# packages

[公式配布ページ](https://zlib.net/)から取得した `zlib-1.3.2.tar.gz` を同梱します。

- 取得元: <https://zlib.net/zlib-1.3.2.tar.gz>
- バージョン: 1.3.2
- SHA-256: `bb329a0a2cd0274d05519d61c667c062e06990d72e125ee2dfa8de64f0119d16`
- ライセンス: アーカイブ内の `LICENSE`

```sh
curl -L -o app/zlib/packages/zlib-1.3.2.tar.gz https://zlib.net/zlib-1.3.2.tar.gz
sha256sum app/zlib/packages/zlib-1.3.2.tar.gz
```

更新時は公式掲載のハッシュと照合し、古いアーカイブを新しいものに置き換え、この文書のバージョンとハッシュも更新します。  
アーカイブは常に 1 個を配置します。  
複数ある場合はファイル名のバージョンが最新のものを選び、未採用のファイルを警告します。  
バージョンを判定できない名前が混在する場合は更新日時で選択します。  
アーカイブがない場合は配置方法を表示してビルドを停止します。

更新後は `make -C app/zlib test` で公開 API の変更と実動作を確認します。  
公開関数が変わった場合は API 表と網羅テストも更新します。  
展開元に必要なファイルがない場合は、展開対象一覧を新バージョンの構成に合わせます。
